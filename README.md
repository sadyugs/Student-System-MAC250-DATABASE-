Student, Course and Enrollment Management System

This project was created for my MAC 250 Database class using HTML, CSS, JavaScript, Node.js, Express, and SQLite.

The application allows users to add, view, update, and delete students and courses, as well as enroll students in different courses.

It includes a simple web interface, a SQLite database to store information, and JavaScript classes for Students, Courses, and Enrollments.

To run the project, install Node.js, open the project folder in a terminal, and run:

npm install

npm start

Then open http://localhost:3000 in your browser.
